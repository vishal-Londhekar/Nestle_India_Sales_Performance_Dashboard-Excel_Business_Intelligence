# Nestlé India Sales Performance Dashboard — Excel

> **Data Analyst & Business Intelligence Analyst portfolio project**

An Excel business intelligence dashboard for analysing sales performance across products, locations, and time periods.

## Overview

The workbook contains the source data, working calculations, KPI summaries, and an executive dashboard. The project demonstrates spreadsheet modelling, formula-based analysis, conditional formatting, chart design, and business storytelling.

## Workbook structure

The following are sheets inside the Excel workbook, not separate repository files:

- **Sales Data** — transaction-level source table
- **Final Working** — KPI calculations and summary tables
- **DashBoard** — executive visual dashboard

## Files

- **Sales Data.xlsx** — Excel workbook
- **README.md** — project documentation

## How to view

1. Open **Sales Data.xlsx** in Microsoft Excel or a compatible spreadsheet application.
2. Review the **Sales Data** and **Final Working** sheets to understand the calculations.
3. Open **DashBoard** to view the executive summary.
4. Refresh formulas or pivots only after checking the workbook's source-data assumptions.

## Analysis areas

- Revenue and unit performance
- Product, state, and city comparisons
- Time-based sales trends
- KPI scorecards and dashboard summaries

## Analyst value

> **Portfolio focus:** Sales Business Intelligence · KPI Reporting · Excel Analytics

**Stakeholder lens:** Sales leaders, category managers, regional teams, and commercial decision-makers.

**Skills demonstrated:** Spreadsheet modelling, KPI design, summary tables, product and geography analysis, formula-based reporting, conditional formatting, and dashboard layout.

**Decision support:** Converts transaction-level sales data into an executive view of revenue, units, products, states, cities, and time-based performance.

## Limitations

- The repository contains an Excel workbook, not a deployed BI application.
- Results depend on the workbook's embedded data and formulas.
- “No server deployment required” is more accurate than “zero licensing overhead”; users still need compatible spreadsheet software.
- Add the dataset source, refresh date, and business definitions for every KPI.
